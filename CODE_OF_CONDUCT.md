# Code of conduct

Web Snap PDF follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to everyone who takes part in the project's issues, pull requests, and reviews.

## Report a problem

To report a comment, issue, or pull request to GitHub, open its `...` menu and choose **Report
content**. GitHub's guide [Reporting abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
shows each step.

To raise a problem with the maintainer, contact [@mahakeerthi](https://github.com/mahakeerthi) on
GitHub. The security advisory form is for security problems only, so do not use it for conduct
reports.
